# Template Generator

Desktop-приложение для конвертации шаблонов **ODS / ODT** в **Eclipse BIRT (.rptdesign)**
с сохранением структуры таблиц, объединений ячеек и базовых стилей.

Приложение предназначено для подготовки BIRT-шаблонов из офисных документов без ручной верстки в Eclipse BIRT Designer.

---

## Для пользователя

### Назначение

Программа позволяет:

* открыть файл **ODS** или **ODT**
* автоматически преобразовать его в шаблон **BIRT (.rptdesign)**
* использовать параметры вида `[param_name]` в тексте и таблицах

Результирующий файл можно открыть и доработать в **Eclipse BIRT Designer**.

---

### Поддерживаемые форматы

* Входные файлы:

    * `.ods` (OpenDocument Spreadsheet)
    * `.odt` (OpenDocument Text)
* Выходной файл:

    * `.rptdesign` (Eclipse BIRT)

---

### Использование

1. Запустите приложение двойным кликом по `run.bat`, который находится в папке  
   `build\libs\` проекта и расположен рядом с файлом `template-generator.jar`.
2. В интерфейсе выберите файл `.ods` или `.odt`
3. Нажмите **Сгенерировать**
4. Полученный `.rptdesign` будет сохранён в выбранную папку

---

### Параметры в шаблоне

В исходном документе можно использовать параметры в квадратных скобках:

```
[tag]
```

Во время генерации они автоматически превращаются в параметры отчёта BIRT и могут быть заполнены при выполнении отчёта.

---

### Требования

* Windows
* Установленная **Java 17 или новее**

---

### Возможные ограничения

* Обрабатывается только **первый лист ODS**
* Максимальный размер таблицы:

    * до 250 строк
    * до 80 колонок
* Сложные стили могут быть упрощены при конвертации

---

## Для разработчика

### Общая архитектура

```
ODT / ODS
   ↓
OdtReader / OdsReader
   ↓
TemplateDocumentIR (IR-модель)
   ↓
TagExtractor
   ↓
BirtDesignBuilder
   ↓
.rptdesign
```

Проект использует промежуточную **IR-модель**, что позволяет:

* валидировать таблицы
* корректно обрабатывать объединения ячеек
* изолировать логику чтения ODF от генерации BIRT

---

### Структура проекта

```
ru.rea.report
├── birt        # Генерация rptdesign через BIRT Model API
├── core        # Общие типы (TemplateType)
├── exception   # Ошибки генерации и шаблонов
├── ir          # Внутренняя модель документа (IR)
├── odf         # Чтение ODT / ODS
├── service     # Сервис конвертации
├── tags        # Извлечение и описание параметров
├── ui          # JavaFX интерфейс
└── TemplateGeneratorApplication  # Entry point
```
